# E-Ration Card Management System

An academic project for managing an electronic ration-card workflow using a Java-based application with HTML/CSS and MySQL.

## Project scope

The project covers a basic digital workflow around ration-card information and management.

## Technology

- Java
- HTML
- CSS
- MySQL

## Repository contents

The repository contains the project source/database material along with supporting screenshots documenting the application.

## How to discuss this project

From a Business Analyst perspective, the useful part of this project is the underlying workflow: capturing user information, maintaining records, connecting application screens to a database, and supporting a government-service-style process.

## Note

This is an academic project and is presented as such. It is not positioned as a production government system.
